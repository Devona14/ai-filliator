Upload data bulanan

Unggah data eligible dan data transaksi setiap bulan. Keduanya ditabrakkan untuk menemukan nasabah yang tidak beli atau top up selama 1 bulan terakhir. File diproses di browser Anda dan tidak dikirim ke mana pun.

1. Data eligible & multiposting

File Excel seperti yang Anda terima mingguan. Sheet berisi kolom account_no_emas, id_mitra, tanggal_pembukaan, amt_trx.

2. Data transaksi 1–2 bulan terakhir

Minimal berisi nomor rekening emas dan tanggal transaksi. Jenis transaksi dan nominal dipakai bila ada.

3. Tabrakkan data

Aktif: ada beli atau top up dalam 30 hari sebelum tanggal acuan. Tidak aktif: transaksi terakhir 31–60 hari lalu. Dormant: tidak ada beli atau top up di seluruh data transaksi. Baru dibuka: umur rekening di bawah 30 hari.

4. File feedback dari Teams

File Excel pipeline yang kolom Status-nya sudah diisi flow Teams. Jawaban affiliator langsung tampil di Radar reaktivasi dan Peta affiliator.

Daftar email affiliator (opsional)

Berisi kolom ID_Mitra dan Email_Affiliator, misalnya sheet Master_Affiliator yang sudah Anda lengkapi. Dipakai untuk mengisi email di file pipeline berikutnya dan hanya disimpan di browser ini.
